Why chunk at all?

Embedding an entire long document as one vector can make retrieval too broad. Chunking allows the system to retrieve the specific passages that answer a question.

8 (toy example)
These are illustrative toy vectors generated from word overlap. Real embedding models use learned numerical representations and usually produce hundreds or thousands of dimensions.

What is an embedding?

An embedding maps text into a numerical vector. Texts with related meaning tend to be closer in the model's vector space, enabling similarity-based retrieval.

What is stored?

Usually: the vector, the original chunk text, and metadata. The vector index helps search quickly; the original text is what the LLM receives as context.
